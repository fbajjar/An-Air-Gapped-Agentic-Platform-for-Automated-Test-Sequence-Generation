# An-Air-Gapped-Agentic-Platform-for-Automated-Test-Sequence-Generation
This Github repo contains the relevant materials for the research paper "An Air-Gapped Agentic Platform for Automated Test Sequence Generation from Multi-Modal Industrial Test Specifications" published to the ICFSET conference.

## Repository organization for reviewer feedback

The repository is organized around the six review points in:

- `/paper_materials/01_reliability_and_scoring`
- `/paper_materials/02_comparators_and_effort_shift`
- `/paper_materials/03_precision_measurement`
- `/paper_materials/04_releasable_artifacts`
- `/paper_materials/05_model_scale_rerun`
- `/paper_materials/06_manuscript_updates`

See `/paper_materials/INDEX.md` for the detailed checklist and file map.
