# An-Air-Gapped-Agentic-Platform-for-Automated-Test-Sequence-Generation
This Github repo contains the relevant materials for the research paper "An Air-Gapped Agentic Platform for Automated Test Sequence Generation from Multi-Modal Industrial Test Specifications" published to the ICFSET conference.
What you will find:

- A synthetic document with results (includes a result for a single prompt through LM Studio which cannot produce .ini)
- An example configuration .yaml file under configs
- A description of the schema that produces that validates the test sequences
- A description of the compiler logic that produces the .ini file

The actual code is confidential.
